# 晨光

给 Natalie 的圣经学习应用：和合本与英文圣经对照阅读、朗读、读经计划、灵修日记、祷告记录、查经资料。界面按中老年使用者设计：大字号、高对比、大按钮。纯网页应用，没有服务器，所有个人记录只保存在自己手机的浏览器里。

## 给使用者的安装说明（可直接转发）

> 读经 App 做好了，叫「晨光」。安装步骤：
>
> 1. 用手机上的 **Chrome 浏览器** 打开这个地址（不要用无痕模式）：
>    https://couldbe518-hub.github.io/lingliang/chenguang/
> 2. 点右上角的 ⋮ 菜单，选「**添加到主屏幕**」（有的手机显示为「安装应用」），确认后桌面上会出现一个日出图标。
> 3. 以后从桌面图标打开，就像普通 App 一样全屏使用。
> 4. 第一次进去后，点右上角齿轮进「设置」，拉到底点「**下载全本**」，之后没有网络也能读经。
> 5. 首页会显示当天的读经进度和一节经文；在「计划」里选一个读经计划（一年读完全本 / 新约 / 旧约，或自己设定）就可以开始了。
>
> 几点说明：
> - 所有笔记、祷告、进度都只保存在你自己的手机里，不会上传到任何地方。换手机前，到设置里「导出备份」，新手机导入即可，建议每个月备份一次。
> - 读经提醒：点「计划」页的「加到手机日历」，让手机日历每天提醒你，这是最可靠的办法。
> - 朗读用的是手机自带的声音。如果没有中文或英文朗读，到手机「设置 → 其他设置 → 文字转语音」安装 Google 语音服务。
> - 点英文单词可以查词，需要联网。
> - 用起来有任何不顺手的地方，告诉 Kevin，这边可以随时改。

## 安装到手机（OPPO / 安卓）

1. 用 **Chrome** 打开应用网址（不要用无痕模式）。
2. 点右上角菜单 ⋮ → **添加到主屏幕**（或「安装应用」）。
3. 以后从主屏幕图标打开，就像普通 App 一样全屏使用。
4. 第一次打开后，进设置 → **下载全本**，之后没有网络也能读经。

OPPO 自带浏览器也能用，但「添加到主屏幕」和离线功能在 Chrome 上最稳定。

## 诚实说明

- **提醒**：网页应用在关闭状态下无法自己响铃，这是安卓对网页的限制。所以提供了「加到手机日历」，由手机日历负责每天提醒。
- **点按查词**：需要联网（使用 Google 翻译的公开接口，失败时自动改用 MyMemory）。查过的单词会保存在本机，之后离线也能看。整句翻译在对照模式下直接看中文即可。
- **朗读声音**：由手机系统提供。OPPO 手机若没有中文或英文声音，到「设置 → 其他设置 → 文字转语音」安装 Google 语音服务即可。
- **密码锁**：是打开应用时的屏幕锁，忘记后无法找回（数据不会丢，但需要先关掉密码才能导出）。真正的保护仍是手机本身的锁屏，加上定期加密备份。
- **浏览器清理**：极少数情况下浏览器可能清理网站数据。添加到主屏幕并经常使用可以避免；仍建议每月导出一次备份。
