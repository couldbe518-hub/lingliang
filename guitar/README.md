# Natalie 吉他

网址：https://couldbe518-hub.github.io/lingliang/guitar/

给 Natalie 的每日吉他练习看板，零基础起步。思路沿用 Grace 钢琴看板：今天 / 曲库 / 识谱 / 录音四个页面，
听示范、跟谱练（弹对自动跳下一个）、跟拍练、录音；谱面换成**吉他六线谱 + 和弦图**，另加**调音器**。
界面按中老年使用者设计（大字、大按钮、高对比，设置里可再调大字号），做成可离线的网页应用（PWA），
所有记录只存在手机里，不上传。日常使用不调用任何 AI，不耗 token。

## 给 Natalie 的安装说明（可直接转发）

> Natalie，吉他练习 App 做好了，叫「Natalie 吉他」。安装步骤：
>
> 1. 用手机上的 **Chrome 浏览器** 打开（不要在微信里打开，也不要用无痕模式）：
>    https://couldbe518-hub.github.io/lingliang/guitar/
> 2. 点右上角的 ⋮ 菜单，选「**添加到主屏幕**」（有的手机显示「安装应用」），桌面上会出现一个吉他图标。以后从图标打开。
> 3. 第一次点「调音器」或「跟谱练」时，手机会问要不要允许使用麦克风，点「**允许**」。
> 4. 每天打开就是「今天」页，按顺序做五步：调音 → 手指热身 → 认谱和和弦 → 练一首歌 →（可选）录一遍。
>
> 几点说明：
> - 手机放在谱架上，话筒朝着吉他，周围安静一点，听得最准。每次先用调音器把六根弦调准。
> - 谱上**亮起的数字**就是该弹的音（线 = 弦，数字 = 第几品，0 = 空弦），下面的指板图也会亮出位置；弹对了自动跳下一个，不用管快慢。
> - 每首歌都有两种弹法：「单音旋律」一个音一个音弹；「和弦扫弦」按住和弦扫弦，上面的大和弦图告诉你现在和下一个按什么。
> - 记录只存在你自己的手机里。换手机前到「设置」导出备份。
> - 用起来有任何不顺手的地方，告诉 Kevin。

## 功能与要求对照

| 要求 | 实现 |
|---|---|
| 三大模式：听示范 / 跟谱练 / 跟拍练 | 曲子页顶部；另有「单音旋律 / 和弦扫弦」切换 |
| 开始跟谱练、跳过这个音/和弦、录音 | 跟谱练控制区三个按钮；提示语按要求更新 |
| 六线谱（线上数字 = 品位） | 自绘 SVG：6 条线、品位数字、下方节奏符干、歌词 |
| 谱面上方的和弦小图，轮到时亮起/放大 | 每次换和弦在小节上方画和弦图，轮到时橙色发光；另有固定的大和弦图面板（现在 + 下一个） |
| 底部四栏：今天 / 曲库 / 识谱 / 录音 | 同钢琴看板；「今天」含调音器入口 |
| 单音模式：识别单弦音高，对了光标前进 | 沿用钢琴看板实测调优的识别：已知目标音时直接测该音能量（快、准），音高算法辅助判错 |
| 和弦模式：多音高识别判断和弦色彩 | 扫弦后 0.17 秒，把 E2–B5 每个半音的能量折算成 12 音名「和弦色彩」，与和弦库每个和弦的理论色彩比相似度；对 → 通关，像别的和弦 → 提示「听起来像 X」，不清楚 → 提示再扫一次 |
| 零基础 | 8 节小课（认识吉他、抱琴、手指编号、六线谱、和弦图、扫弦、五个常用和弦、调音）；识谱练习（空弦、1–3 弦、六根弦第一把位、看图认和弦） |

## 曲库（25 首）
- 基础练习 10：拨空弦、1/2/3 弦的音、爬格子、C 大调音阶、Em↔Am、G↔C、G↔D、扫弦节奏
- 赞美诗 5：欢欣歌颂、耶稣爱我、奇异恩典、三一颂、平安夜
- 经典歌曲 10：小星星、玛丽有只小羊羔、小蜜蜂、两只老虎、铃儿响叮当、念故乡、生日快乐、送别、友谊地久天长、绿袖子

歌曲的旋律、和声与歌词取自 Grace 钢琴看板里已核对过的版本，移到吉他好弹的调（大多 G 大调，只用 G、C、D、Em），
旋律自动排在第一把位（0–4 品）。生成脚本思路：钢琴右手 → 移调 → 动态规划选弦；钢琴左手低音 → 推出每小节和弦。

## 测试（合成吉他声，电脑上模拟）
- 单音：小星星前 14 个音（含走音 20 音分）全部判对，误判 0–1 次。
- 和弦：G G C G D G Em Am 八下全部判对；Em↔Am、G↔C（走音 8 音分）跟谱练均 100 分；故意扫错时能报出「听起来像 C」。
- 真吉他上的效果需要 Natalie 实际使用后再调。
