# 灵粮读经

和合本（1919）与 Berean Standard Bible / KJV 中英对照的圣经研读与祷告网页应用：逐章概要、经典经文释义、情境找经文、中英朗读、每日读经打卡、早晚祷陪伴。

- 经文：和合本、BSB、KJV 均为公共领域。
- 章节概要、释义、情境推荐与祷告文为原创内容。
- 所有个人记录（打卡、收藏、代祷）只保存在使用者自己设备的浏览器中，不上传。
- 经文可五色高亮（应许/教导/提醒/安慰/祷告）、成段标记、写经节注释与整章默想，在「查找」页集中查看；阅读背景与文字颜色可选。
- 首次联网后自动把全本经文存入手机，离线可读；备份可导出为文件并在新手机导入。

## 给使用者的更新说明（可直接转发）

> 灵粮读经更新了几个功能，联网打开一次就会自动换成新版，原来的打卡、收藏、代祷都不受影响：
>
> 1. **经文高亮**：读经时点一节经文，可以选五种颜色，分别代表应许、教导、提醒、安慰、祷告；还可以选「到第几节」，一次把一段都标上。经典经文的释义面板里也有「高亮 · 注释」按钮。
> 2. **注释和默想**：每节经文可以写注释，会显示在经文下面；每章末尾有「本章默想与领受」，可以记整章的领受和祷告。
> 3. **集中查看**：「查找」页的「我的收藏与标记」里，可以按颜色、注释、整章默想分类翻看以前标过的经文。
> 4. **离线读经**：第一次打开后联网等一分钟左右，应用会自动把全本圣经存进手机，之后没有网络也能读；进度在设置里的「离线」一栏可以看到。
> 5. **备份更方便**：设置 › 备份与恢复里，现在可以「导出备份文件」，直接发给自己的微信、邮件或存到 iCloud；换手机时在新手机「导入备份文件」就全部回来了。高亮和注释都包含在内。
> 6. **阅读颜色**：阅读设置里可以换暖黄、浅绿、浅蓝、浅粉背景，经文文字也可以选深褐、深蓝等颜色，看着更舒服；不改就还是原来的样子。
>
